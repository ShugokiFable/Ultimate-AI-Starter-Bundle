# v7.5.2 — audit pass: version drift, a pinned install tag, and root clutter

Found by auditing the pack rather than running it. No skill content changed.

## The install one-liner fetched an old release

`README.md` and `INSTALL-REMOTE.ps1` both advertised the copy-paste remote
install with `-Tag v7.5.0` hard-pinned:

```powershell
... INSTALL-REMOTE.ps1))) -Providers Claude,Grok -Tag v7.5.0
```

`INSTALL-REMOTE.ps1` already treats an empty tag as "latest release", so the
pin was doing nothing except freezing every documented install at 7.5.0 —
including installs run after 7.5.1 shipped. The pin is removed from both. The
`.PARAMETER Tag` example now says 7.5.2 and states explicitly that empty means
latest.

## The installer reported the wrong version

v7.5.1 shipped with `INSTALL-V7-AIO.ps1` still carrying 7.5.0 in two places
that users and logs actually see:

- the startup banner (`Ultimate AI Starter Bundle v7.5.0 - ALL-IN-ONE INSTALLER`)
- the internal `version = '7.5.0'` field

Both now track the release. The two remaining `v7.5.0` mentions in that file
are prose describing when the SOUL/AIO preamble feature landed, which is
correct as history and was left alone.

## Duplicate file removed

`AIO Instruction.txt` was byte-identical to `AIO-INSTRUCTION.txt` — leftover
from a rename that deleted the file in the working tree but never committed.
Removed. `MANIFEST.json` had drifted and still listed it.

## Root decluttered

26 per-version changelogs and v4/v5-era audit documents moved to
`docs/history/`. The pack root drops from 33 markdown files to 7, so a new user
(or an agent pointed at the repo) sees only current documentation. Nothing was
deleted — every changelog and audit is still in the repo and in git history.

Moved: `RELEASE-NOTES-v5.2.2.md`, `V4.2-LOG-REGRESSION-AUDIT.md`,
`V4.3-CLAUDE-REVIEW-AUDIT.md`, `V5-INTEGRATION-AUDIT.md`, `V5-CHANGELOG.md`,
and every `V6*`/`V7*` dated changelog. `CHANGELOG.md` stays at the root as the
current-version file the completeness gate reads.

One prose reference to `V7.4.2-CHANGELOG.md` inside `INSTALL-V7-AIO.ps1` was
repointed at the new path.

## Unrestraint preamble relocated

The operator's unrestraint preamble moved from the pack root into
`0-UNRESTRAINT-PACKS/`, where that material already lives.

## Deliberately not changed

Roughly 72 MB of byte-identical reference payloads (`papyrus-reference`,
`mutagen-reference`, the houseCARL setup PDF) are duplicated up to 11 times
across the five provider trees and `_V7-CANONICAL-SKILLS`.

This is not bloat worth removing. Git stores identical blobs once, so the
repository does not pay for it — only the extracted tree and the release zip
do. The duplication exists so each provider tree is self-contained and can be
copied directly into that provider's skills directory. Collapsing it into a
shared reference directory would save zip size at the cost of the
one-command install, which is the wrong trade for this pack.

## The release gate blocked its own release commit

`completeness_gate.py` treated staged changes as missing from the release.
Porcelain status is two columns, XY; the check ignored Y entirely, so a
staged-and-clean file (`M `) read as uncommitted. With HEAD having touched
a version file, the gate then refused every `git commit` carrying a code
file - including the commit that completes the release. It now skips
entries whose worktree column is clean, and resolves renames to their
destination. Self-test gained both directions: staged code silent,
unstaged code still reported.
