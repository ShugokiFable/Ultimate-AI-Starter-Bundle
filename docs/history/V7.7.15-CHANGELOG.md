# v7.7.15 — Pre-release checklist skill for every provider

New canonical skill `release-checklist` fanned out to all five provider trees
(Claude, Codex, Grok, Hermes, Kimi — 487 skills each).

Encodes the v7.7.13/7.7.14 failure class so it cannot recur: read the CI
workflow before editing, bump every version string CI checks (including the
dated changelog `docs/history/V7.X.Y-CHANGELOG.md`), regenerate and verify
`MANIFEST.json` after any file change, run the local pack gate, push and WAIT
for CI green before tagging, build release zips from the green commit, and
verify the published assets. Includes the recovery sequence for releases that
already shipped red (delete release, force-move tag, rebuild, republish).

Also applied the checklist to this very release: all six version-string
locations bumped, dated changelog created, MANIFEST regenerated (3775 files)
and verified, pack gate PASS, then push and CI verification before tagging.
