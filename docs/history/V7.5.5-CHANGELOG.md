# v7.5.5 CHANGELOG - Hermes config.yaml wiring + complete "What's new" + stale version metadata fixed

2026-08-18

## Hermes config.yaml now ships and installs

The operator's live Hermes config (model routing, MCP servers, hooks, platform
toolsets) is now part of the pack at
`1-RECOMMENDED-SEPARATE-TAILORED/Hermes/config.yaml`, byte-identical to the
live `%LOCALAPPDATA%\hermes\config.yaml`.

- **`INSTALL-V7-AIO.ps1`** gained a Hermes config.yaml wiring step (new
  `-SkipHermesConfig` opt-out): copies the tailored config into the Hermes
  home (catalog-resolved: `%LOCALAPPDATA%\hermes`, `HERMES_HOME` overrides),
  backup-first (`.before-config-<ts>.bak`), hash-compare idempotent. Same
  pattern as the SOUL wiring. Verified against a scratch home: fresh install,
  no-op on identical, backup + byte-identical restore on change.
- **`1-RECOMMENDED-SEPARATE-TAILORED/Hermes/COPY-MAP.md`** corrected: Hermes
  home default was stale `%USERPROFILE%\.hermes` (fixed to
  `%LOCALAPPDATA%\hermes` in the catalog back at v7.5.0, never propagated
  here); config.yaml placement documented.
