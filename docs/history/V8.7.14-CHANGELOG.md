# v8.7.14 -- Scoped code graph memory and evaluated video/graph candidates

Hermes now has a native `code` profile with codebase-memory-mcp. It inherits the
three verified core servers but leaves codebase-memory out of `default`, so
ordinary Hermes sessions do not pay its schema cost. The profile is created
only when the native binary exists and is selected with `hermes -p code`.

The first live dry run exposed an older creation-path defect: the migrator
planned `profile create` and then queried that not-yet-existing profile for
preferences before the apply phase. Planned clones now read the default
preferences they will actually inherit. The applied migration is backed up,
the second run is a no-op, and the real Hermes initialize/tools-list handshake
returns all 15 codebase-memory tools. A separate config check proves Hermes
default still contains only context7, GitHub and Headroom.

Codebase-memory 0.10.8 was re-measured at 23,974 schema bytes, about 5,994 tokens
per enabled turn. Its fifteenth tool, `check_index_coverage`, is now documented.
Claude and Grok retain project-scoped `code-intel`; Codex and Kimi remain
unregistered by default because neither has repository-scoped MCP config.
`auto_index=false` and `auto_watch=false` are unchanged.

Two requested candidates were tested rather than installed on reputation:

- OpenMontage completed 1,829 tests, with 11 skips and 3 expected failures. It
  is a genuine video-production capability but stays a separate specialist
  project: 1,057 skill markdown files and unlocked lower-bound dependencies do
  not belong in every provider's global skill tree.
- Graft completed 1,214 tests with 6 skips, built and checked its own graph, and
  exposed only 6 MCP tools / 3,363 schema bytes (~841 tokens). It remains
  watch-only because its structural tier overlaps codebase-memory, the first
  natural-language query missed without deep/model-backed indexing, and
  `graft init` writes provider hooks, skills and configs already owned by UABS.

No always-on MCP schema was added. The pack still ships 167 canonical skills
across all five provider trees.
