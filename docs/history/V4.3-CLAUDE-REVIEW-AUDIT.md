# V4.3 Claude review adjudication

## Confirmed findings

- `audit_bos_configs.py` had a real false negative: it only found duplicate targets and never inspected transform syntax.
- SPID `ExclusiveGroup` is a real special key.
- SPID `DeathItem` is a real on-death key.
- trailing semicolon comments must be normalized before offline field parsing when runtime has accepted the row.
- the CDF wildcard-like `add` defect remains valid and belongs to the affected mod, not the skill-pack release.

## Corrected or narrowed findings

- Publication alone does not prove a config is valid. The new rule uses parser and runtime evidence, not popularity.
- KID ordinary rows do not support a blank type under pinned 4.0.6. Blank type leaves `kNone` and the row is skipped.
- KID record signatures such as `WEAP` are not unresolved: the pinned `GetType` accepts exact human-readable labels only.
- KID `ExclusiveGroup` is the separate no-type grammar and was the missing exception in the old linter.

## Production regression policy

Synthetic helper tests are no longer enough. The truth verifier invokes the real
CLI/auditor on production-shaped rows, including the exact BOS whitespace shape.
