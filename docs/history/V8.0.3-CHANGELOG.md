# Ultimate AI Starter Bundle V8.0.3

V8.0.3 completes the Hermes OpenRouter repair and ships it through the one-click installer.

- Hermes receives the same marked canonical SOUL + AIO contract as every other provider instead of reverting to the short base soul.
- The retired `openrouter-extra` provider is removed from config and resumable session overrides in `state.db`, with backup-first targeted rollback data.
- Missing-only compression defaults use a 200,000-token threshold without replacing explicit user settings.
- The normal `openrouter` picker uses OpenRouter's full live tool-capable catalog instead of Hermes' curated allowlist, including newly listed free models such as `dots-studio/dots-3-note-preview:free`.
- The compatibility shim lives outside Hermes' tracked Git source so ordinary `hermes update` operations do not reset it.
- 146 canonical skills ship across the supported provider trees.
