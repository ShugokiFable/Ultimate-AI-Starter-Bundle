# v7.7.9 - Installer respects existing tool installs; tuned Hermes compression

## AIO keeps existing houseCARL / Spooky installs

`INSTALL-V7-AIO.ps1` no longer force-installs houseCARL or Spooky's AutoMod
Toolkit over a live/working copy. If `HOUSECARL_MCP` points at a valid
`housecarl-mcp.exe` (or `SPOOKY_AUTOMOD_ROOT` at a folder containing
`SpookysAutomod.sln`), the installer records `kept-existing` and never
overwrites - the same pattern codebase-memory already used. Users who keep
curated tool copies elsewhere (e.g. a personal tools drive) can point the
env vars at them and re-run the AIO safely.

## Tuned Hermes compression defaults

`1-TAILORED-PROVIDER-TREES/Hermes/config.yaml` compression block now matches
the tuned settings proven on the maintainer's machine:

- threshold 0.25 -> 0.14, target_ratio 0.15 -> 0.11 (compacts earlier)
- protect_last_n 20 -> 6 (leaner tail protection)
- progress_notices on
- new keys: `proactive_prune_min_result_chars`, `proactive_prune_min_reclaim_tokens`,
  `in_place`, `idle_compact_after_seconds`, and the codex_* compaction settings

The template stays portable: no machine paths, MCP servers and hooks are
still wired by the AIO from discovered local tools.
