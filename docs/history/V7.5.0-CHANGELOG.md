# V7.5.0 CHANGELOG — the soul ships, and a fresh machine is one command

2026-08-16

The pack always stopped at the edge of this job: it installed skills, tools and
MCP servers, then told the user to paste `AIO-INSTRUCTION.txt` into custom
instructions "by hand" because that one is a UI field. v7.5.0 closes it. The
operator's own SOUL config and the AIO operating contract are now part of the
install, and the whole thing can be started from an empty Windows machine with
one command.

## What's new

- **`4-PREAMBLES/`** — new pack section.
  - `SOUL.md` — the operator's actual Hermes soul config, verbatim. The only
    change is removing one copy-paste debris line ("The Truth Prompt 2026
    Page 3"). This is the persona: unrestricted, no yes-man, truth-seeking
    process, output format.
  - `SOUL-UNIVERSAL.md` — identical content with an identity-neutral opening
    ("You are Hermes Agent" is true for Hermes and false for everyone else).
    This is the file the installer actually appends.
  - `MANUAL-PASTE.txt` — SOUL-UNIVERSAL + the Fun-stuff-kit `AIO.txt`,
    concatenated for web UIs (ChatGPT/Gemini) that have no instruction file.
  - `README.md` — wiring map per provider.
- **Universal preamble wiring in the installer.** `INSTALL-V7-AIO.ps1` now
  appends a marked block (SOUL-UNIVERSAL + the pack-root operating contract)
  to:
  - Claude Code -> `%USERPROFILE%\.claude\CLAUDE.md`
  - Codex        -> `%USERPROFILE%\.codex\AGENTS.md`
  - Kimi         -> `%USERPROFILE%\.kimi-code\AGENTS.md`
  - Grok         -> `%USERPROFILE%\.grok\AGENTS.md` (Grok's documented global
    rules file - applies to all projects)
  - Hermes       -> `%LOCALAPPDATA%\hermes\SOUL.md` (verbatim soul copy)
  Idempotent (re-run replaces the marked block, never stacks), `.bak` before
  every write, UTF-8 no BOM, created-if-missing for fresh machines.
  `-SkipPreamble` opts out, `-ForcePreamble` rewrites an identical block.
- **`INSTALL-REMOTE.ps1` + `INSTALL-REMOTE.bat`** — install from zero:

  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/ShugokiFable/Ultimate-AI-Starter-Bundle/main/INSTALL-REMOTE.ps1 | iex"
  ```

  Resolves the latest release, downloads the zip, extracts to
  `%LOCALAPPDATA%\Ultimate-AI-Starter-Bundle\<tag>`, runs the real installer.
  Re-runs are no-ops; `-Tag` pins, `-Force` re-downloads. Releases now carry a
  zip asset (previous releases had none; the script falls back to the GitHub
  source archive if an asset is missing).
- **`BOOTSTRAP.txt` rewritten for a fresh machine.** The one-paste agent
  bootstrap now includes "download the bundle first" when no local copy
  exists, instead of assuming one.
- **Catalog fix: Hermes home was `%USERPROFILE%\.hermes`.** Hermes' actual
  config home on Windows is `%LOCALAPPDATA%\hermes` (`hermes config path`).
  Every previous install that targeted `~\.hermes` silently wrote skills next
  to the real home. Corrected to `%LOCALAPPDATA%\hermes` (env override
  `HERMES_HOME` still wins).
- The installer's `state.version` finally reports the real version (was a
  leftover `'5.0.0'`).

## What did NOT change

- The pack-root `AIO-INSTRUCTION.txt` (operating contract) is untouched,
  still ~614 tokens, still the installed contract.
- `PROMPTS/AIO-INSTRUCTION.txt` remains the leftover jail paste, still NOT
  wired. The wired preamble is SOUL-UNIVERSAL + the root contract.
- Fun-stuff-kit contents are unchanged (already synced in v7.4.x).
- Zero skill-tree changes: 92 canonical skills, 10 provider trees untouched.

## Cost and caution

- The preamble block is ~1.4k tokens riding on every request of every wired
  agent. That is the point (it is what the operator runs), but it is also why
  `-SkipPreamble` exists. Web-UIs: paste `MANUAL-PASTE.txt` only where the
  box exists.
- Preamble append/replace logic was sandbox-tested (fresh file, existing
  file, BOM file, re-run replace, -Force). The remote bootstrap was parsed
  and its download/extract path exercised against a local archive. The full
  installer still has NOT been run end-to-end on a clean machine - the pack
  gate (`TESTS\Test-V7-Pack.ps1`) remains the control.
- The universal soul deletes the "You are Hermes Agent" identity line from
  the opening. Same weight, same rules, no misbranding.
