# Ultimate AI Starter Bundle V8.0.0

V8 makes the bundle updateable as one owned product instead of a collection of version-stamped/manual drops.

- Stable entry: `START-HERE.bat`; stable implementation: `INSTALL-AIO.ps1`.
- Stable installed pack: `%LOCALAPPDATA%\Programs\Ultimate-AI-Starter-Bundle`.
- Stable state: `%LOCALAPPDATA%\Ultimate-AI-Starter-Bundle`.
- Five providers: Claude, Codex, Grok, Kimi, Hermes.
- 146 canonical skills, fanned out to all five provider trees.
- Full catalog installed by default; credentialed MCPs wait for their credentials and project/editor MCPs remain scoped.
- Official Codex plugin marketplace/install/remove commands replace the old hand-written TOML marketplace.
- Managed skill ledger cleans unchanged retired bundle skills while preserving modified and user-owned skills.
- Context7, official GitHub MCP, and Headroom are refreshed for all selected providers and handshake-tested before success.
- Child PowerShell and Bun discovery use real executable paths, including tools installed during the same run; locked bundle helpers are stopped by exact path before replacement.
- Hermes MCP cleanup and argument writes preserve JSON arrays for both one and many values, with regression coverage for both shapes.
- The claude-mem official installer disables anonymous telemetry and starts its worker; the old `%LOCALAPPDATA%\Skyrim-AI-V5` state is migrated and retired without deleting unrelated data.
- Remote update is atomic, retains one rollback, and removes only marker-verified old versioned bundle folders.

Historical V7 changelogs are retained unchanged as release history.
