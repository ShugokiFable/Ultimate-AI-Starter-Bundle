# v8.7.4 -- Codex skill-root convergence

**2026-08-30.** Based on v8.7.3 (e8d7fa5). **167 canonical skills**, no new
tools and no new always-on MCP schemas.

## Fixed

- Codex built-in skill names are discovered from `<CodexHome>\skills\.system`
  before synchronization and excluded from the copy set. They never appear
  transiently under supported `~/.agents/skills` and never enter the managed
  ownership ledger.
- A previously managed, unchanged excluded copy is retired through the same
  digest ledger. A modified copy is preserved rather than overwritten or
  deleted.
- Codex's deprecated `~/.codex/skills` root now archives non-pack duplicates
  only when the complete tree digest exactly matches the copy in supported
  `~/.agents/skills`. Unique, modified, and reparse-point skills remain.

## Regression proof

- `TESTS/Test-ProviderSkillSync.ps1` installs a provider-owned skill, excludes
  it on the next run, and proves both its installed directory and ledger entry
  disappear while a modified retired skill and unrelated user skill remain.
- Release contracts bind dynamic pre-sync discovery, exclusion at the shared
  sync call, the backup-safe post-plugin remover, and exact cross-root digest
  comparison.

Windows MCP remains installed and manually opt-in. It is useful for native UI
Automation on a host that needs it, but its 20 schemas (~5,522 tokens per turn)
and machine-wide mutation surface make it the wrong default.
