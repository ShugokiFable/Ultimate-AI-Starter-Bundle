# v8.7.16 -- Grok hook repair and complete GitHub projects

Grok 1.0.13 was loading two native Stop hooks and two incompatible inherited
Claude copies after its compatibility table disappeared. The native commands
parsed; the inherited copies failed PowerShell parsing. The standalone hook
installer now repairs that setting while preserving other user choices and
uses the shared resolver to store a verified Python interpreter.

The doctor checks effective compatibility as well as discovered hooks. Tests
cover fresh/reset configurations, LF/CRLF, backups, repeat installs, preserved
personal settings and later MCP tables, invalid owned values, duplicate hooks,
disabled discovery, and malformed native commands. All five repaired live hook
commands completed with exit 0 in about 0.2 seconds each using harmless payloads.
A full Grok inference turn was not run.

The live skills-only install also exposed a Codex regression: built-in skill
deduplication ran only when plugin updates were enabled. It now runs once after
either plugin path, preserving modified duplicate copies in the existing backup
mechanism. This fixes a repeated `skill-creator` index entry without updating or
reconfiguring plugins.
Installer completion messages now report when handshakes, preamble updates, or
cleanup were skipped instead of claiming those actions ran.

The existing GitHub maintenance skill now also handles one new repository.
Coding and completion skills route to a concrete baseline: working CI, applicable
code scanning, independently verified dependency/security settings, reporting,
useful public documentation, usable artifacts and verified release downloads.
Existing publication approval is reused; missing approval is requested only
after the concrete release is prepared. All five provider trees retain the
same 167 canonical skills. No new server or index entry is added.

The user's existing deletion of an obsolete tracked SOUL backup is retained;
the current instruction source is unchanged. CI, artifact and publication proof
belongs to the final commit and release, not to a claim written before those run.
