# v7.7.14 — Live → bundle provider sync

Portable touches from the reference machine's live configs were missing from
the tailored provider trees:

- **Claude `settings.json`** — `enabledPlugins` added: claude-code-setup,
  claude-mem, headroom, obsidian, ponytail, superpowers. The marketplaces
  were already declared under `extraKnownMarketplaces`; the enable flags were
  not, so a fresh install knew the sources but had nothing enabled.
- **Codex `config.toml`** — default `model = "gpt-5.6-sol"` added (parent and
  installer copy mirrored).

Machine-specific wiring (MCP command paths, hooks, runtime dirs) stays out of
the templates by design — the installer discovers and writes those.

config, `Repair-McpPaths.ps1` Claude-Desktop coverage + unversioned-stem
