# V7.5.4 CHANGELOG - common unrestraint skill and current Grok MCP wording

## Changed

- `unrestraint-packs` is no longer provider-scoped. The canonical source now
  fans it out to Claude, Codex, Grok, Kimi, and Hermes.
- Updated the installer help and comments that still claimed Grok had a
  five-configured or six-running-server limit. The measured boundary is eight
  running servers; retain a six-configured budget when a plugin supplies one.

## Not changed

- Existing Grok MCP configuration is not rewritten by this change. Grok's
  current native server list and Claude-compat settings remain operator-owned.
