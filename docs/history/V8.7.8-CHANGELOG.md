# v8.7.8 -- local and fresh-install convergence

**2026-09-01.** Based on v8.7.7. **167 canonical skills**; no new MCP schemas.

This release closes two maintenance gaps found by auditing a long-lived install
against the current catalog.

- The web profile and catalog now agree on shadcn 4.19.1. Context7's damaged-
  catalog fallbacks and current command examples now agree with its existing
  4.0.4 catalog pin.
- CodeBurn 0.9.23 now carries the official npm registry integrity and installs
  with lifecycle scripts disabled.
- Older pack releases could install CodeBurn or Impeccable through Hermes'
  private Node prefix. Once normal npm won PATH, later upgrades landed in the
  active global root but left the old package and dependencies behind. After a
  successful exact-version install, v8.7.8 asks that private npm to uninstall
  only a strictly lower version. A missing active package, mismatched catalog
  version, equal/newer private copy, or ambiguous npm root is left untouched.
- Grok MCP diagnostics no longer repeat the retired npm GitHub server or assume
  Claude compatibility owns Grok's MCP list. They now describe native Grok TOML
  and the bundle's explicit `compat.claude mcps=false` topology, without
  presenting one maintainer machine's server count as a universal invariant.

Windows MCP remains installed but off by default. RTK remains installed by
default with only its tested status/test allowlist; the lossy broad upstream
rewrite table is still disabled.
