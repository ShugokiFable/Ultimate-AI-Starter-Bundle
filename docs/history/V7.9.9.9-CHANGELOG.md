# V7.9.9.9

Incident remediation + provider cleanup.

- **Security incident:** `config.MAINTAINER.yaml` (a copy of a personal live
  Hermes config) shipped as a tracked file in v7.9.9.6-v7.9.9.8 and inside the
  v7.9.9.4 release zips. No API keys were ever present (`key_env` names only),
  but machine usernames/paths leaked. Remediation: file removed from HEAD,
  entire git history rewritten with `git filter-repo` tags force-pushed to scrubbed
  history, poisoned v7.9.9.4 GitHub release deleted.
- Removed the static `openrouter-extra` provider block from the starter
  template and from maintainer guidance. Native OpenRouter discovery serves
  all current models (dots-3-note-preview, nemotron-3-ultra, ...) in the
  normal model list; the pinned 4-model `discover_models: false` dropdown was
  a relic that gated users out of live discovery.

Shipped skills: 146.
