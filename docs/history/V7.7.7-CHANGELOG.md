# v7.7.7 - Hermes keeps plugin skill copies (slash commands + autofill)

Hermes derives `/skill-name` slash commands and the desktop autofill from
the skills directory (`scan_skill_commands` scans `SKILLS_DIR`, not plugin
registrations). The native-plugin dedupe deleted the Superpowers and
Ponytail copies from that path, so `/using-superpowers` (and the rest)
stopped autocompleting and returned `Unknown command` after a restart —
same failure class as the Grok TUI issue in v7.7.5.

Fix: Hermes no longer runs the dedupe for superpowers/ponytail, mirroring
the Grok exemption. Claude/Codex/Kimi still dedupe (their plugin systems
load plugin skills natively). The installer test now asserts the Hermes
exemption. Copies were restored on the live machine from the dedupe
backups.
