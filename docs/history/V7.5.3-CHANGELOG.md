# v7.5.3 — houseCARL pointed at a path called "C"

Found by running the installer against a real machine rather than reading it.

## `SKYRIM_MO2_INSTANCE` was set to a single character

`Setup-HouseCarl.ps1` persisted this:

```
SKYRIM_MO2_INSTANCE       = C
HouseCarl__Mo2InstanceDir = C
```

`Find-Mo2Instances` builds a `List[string]` and returns it. PowerShell unrolls a
single-element return to a bare `[string]` on the way out. A string still
answers `.Count = 1`, so `$mo2List.Count -ge 1` passed and the MO2 branch ran —
and `$mo2List[0]` then indexed the **string**, yielding the first character of
`C:\...`.

So the failure only reproduces when the machine has **exactly one** MO2
instance. Two or more returns a real array and works fine, which is why this
survived. The result is a houseCARL configured against a path that never
existed: the server starts, and every load-order read fails.

Two changes:

- `$mo2List = @(Find-Mo2Instances)` forces array semantics. The `@()` is
  load-bearing and now carries a comment saying so, because it looks removable.
- A guard before the environment is persisted refuses any instance directory
  without a `ModOrganizer.ini` and exits non-zero, rather than writing a bogus
  value silently. Silent is what made this expensive to find.

## `CATALOG.json` declared the wrong pack version

`BUNDLED-TOOLS/CATALOG.json` still said `pack_version` 6.8.0 with an
`updated_utc` of 2026-08-02 — seven minor versions behind `VERSION.txt`.
Anything reading the catalog to decide what this pack is got the wrong answer.
Both fields now track the release.

## Dangling references left by 7.5.2

The 7.5.2 cleanup moved 26 changelogs into `docs/history/` and deleted the
duplicate `AIO Instruction.txt`, but three references to the old locations
survived:

- `START-HERE.txt` still carried a `V7.5.1` title (missed in the 7.5.2 bump).
- `START-HERE.txt` told readers the operating contract was "also on disk as
  `AIO Instruction.txt`" — a file 7.5.2 removed.
- `START-HERE.txt`'s READ NEXT list pointed at bare `V7.x-CHANGELOG.md`
  filenames that now live under `docs/history/`.
- `README.md` repeated the same "also stored as `AIO Instruction.txt`" claim.

All corrected. Mentions inside historical changelogs are left alone, since they
describe what was true at the time.
