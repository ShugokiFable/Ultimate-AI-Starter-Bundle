# v8.7.3 -- creative capability without tool soup

**2026-08-30.** Based on v8.7.2 (a182927). **167 canonical skills**, up from
164. No new always-on MCP schemas.

## Added

- **img2threejs v1.5.1** at exact commit
  `dede5909be4e494b228c801a55dda47439143932`: a stdlib Python pipeline that
  turns a reference image into a staged procedural Three.js reconstruction.
  UABS adds a UTF-8 Windows Python resolver, path-containment guard, and
  no-bytecode wrapper behavior so provider skill trees stay clean.
- **Impeccable skill 4.1.2 + CLI 3.6.0**: a cross-provider UI craft router and
  executable HTML/CSS detector. The official skill archive and npm integrity
  are bound in the catalog. Optional Puppeteer is omitted because Playwright
  already owns live browser inspection.
- **Safe skill discovery** through pinned `skills@1.5.23`. Its wrapper disables
  telemetry and exposes only `find`; accepted candidates still enter through
  immutable provenance review and canonical fanout.

## Profile convergence

`INSTALL-AIO.ps1` now runs `Set-McpProfile.ps1 -Repair` over profile scopes the
pack already owns. Installing a missing MCP after a profile was enabled repairs
that profile on the next installer run without detecting or enabling anything
new, widening it to another provider, or forgetting an existing Grok entry at
the MCP budget ceiling. The `web` profile also stopped matching every Node
project: an ordinary backend `package.json` no longer activates Playwright and
Chrome DevTools.

Commented TOML MCP tables now count as disabled in both the profile writer and
installed-state doctor. This closes the live case where Windows MCP had been
commented out in Codex but was still reported as registered and could block a
later explicit re-enable.

Windows MCP remains installed, opt-in, and impossible for `-Auto` to activate.
It is not useless: it remains the fallback for hosts without native desktop
control and can expose native controls through UI Automation without repeated
vision calls. It is not a sensible default because its 20 schemas cost ~5,522
tokens on every turn and its tools can mutate the whole machine. Native
computer-use availability varies by provider, so current profile guidance no
longer claims universal duplication.

The retired-skill generator also now requires a path below a skill directory.
Canonical-root notice files can no longer be mistaken for stale skills and
offered to cleanup.

The live install also caught a v8.7.1 fresh-shell regression after Headroom's
successful uv upgrade: `Refresh-ProcessPath` existed only inside the provider
bootstrap script, so the parent installer could not call it. That helper is now
shared and contract-bound.

## Evaluated, not added

- Agent-Reach v1.5.0: 154 tests pass and 8 skip, but even `doctor` mutates an
  isolated home and its many delegated CLIs overlap existing web/GitHub tools.
- taste-skill: prompt-only overlap with Impeccable and frontend-design.
- OmniRoute: a credentialed provider gateway, not a cheaper MCP schema router.
- Playwright MCP and Anthropic's official marketplace: already installed and
  deliberately selective; no duplicate was added.
