# v7.6.7 — the root folders are numbered 0, 1, 2, 3 again

v7.6.6 deleted `2-OPTIONAL-SHARED-GENERIC` and left the pack root reading
`0, 1, 3, 4`. The operator noticed before we did. This release closes the
gap and, while doing it, removes a name that had stopped meaning anything.

## The renames

| Before | After |
|---|---|
| `0-UNRESTRAINT-PACKS/` | unchanged |
| `1-RECOMMENDED-SEPARATE-TAILORED/` | `1-TAILORED-PROVIDER-TREES/` |
| `3-OPTIONAL-MANUAL-OTHER-GAMES-MEGA-PACK/` | `2-OPTIONAL-MANUAL-OTHER-GAMES-MEGA-PACK/` |
| `4-PREAMBLES/` | `3-PREAMBLES/` |

`RECOMMENDED-SEPARATE-TAILORED` was half of a recommendation — *recommended*
versus the *optional shared generic* tree. With that tree deleted in v7.6.6,
the name answered a question the pack no longer asks. `1-TAILORED-PROVIDER-TREES`
says what the folder is.

## References moved with them

Every live reference was updated in the same commit, so there is no commit
where a path points nowhere:

- `INSTALL-V7-AIO.ps1` — the tailored-tree source path, the Hermes config
  source, the preamble directory, the missing-preamble warning, and the
  web-UI paste hint.
- `TESTS/Test-V7-Pack.ps1` — the skill-tree family loop and the three
  `4-PREAMBLES` sites in the preamble gates.
- `TOOLS/fanout_providers.py` — the `TAILORED` target constant.
- `TOOLS/generate_manifest.py` and `.gitignore` — the mega-pack special cases.
- `README.md` layout map, `START-HERE.txt`, `BOOTSTRAP.txt`,
  `V7-AIO-GUIDE.md`, `PROMPTS/README.md`, the preambles' own README, and the
  unrestraint-packs README.

Verified by grep after the edit: zero references to any old name anywhere
live. Historical changelogs (`CHANGELOG.md` past sections, `docs/history/`,
`VALIDATION.json` notes) deliberately keep the names that were true when they
were written — rewriting those would make the history wrong, not tidier.
