# v8.7.9 -- security and same-day dependency convergence

**2026-09-02.** Based on v8.7.8. **167 canonical skills**; no new always-on MCP schemas.

This release closes the actionable roots behind the generated CodeQL alert set and adds an operator-run freshness check so same-day upstream releases cannot hide behind a stale README.

- Superpowers no longer reflects its local companion bearer key into bootstrap JavaScript or browser storage. The server URL-encodes the initial query, stores an encoded HttpOnly SameSite cookie, strips the visible URL, and authenticates same-origin WebSockets with that cookie. Focused tests use a hostile `</script>` token and pass all HTTP, cookie, origin, and reconnect cases.
- Impeccable advances to skill 4.1.3 and CLI 3.6.1 from official checksum/integrity-bound assets. UABS preserves its Apache license, excludes upstream self-update/generated cache state, bounds poll and lease retention, escapes literal regex inputs, accepts browser-valid malformed script/style closing tags without leaking their bodies into analysis, and decodes HTML evidence entities in one pass.
- Ponytail's mode parser no longer has overlapping whitespace/label repetitions; a 100,000-space malformed line is the regression. The release-contract vision lookup now scans once per line instead of using a nested multiline expression.
- Playwright MCP 0.0.80 (24 tools, 18,502 schema bytes) and shadcn 4.20.0 (7 tools, 4,495 bytes) are measured project-profile pin updates. Blender MCP 1.9.1 is measured at 28 tools and 29,274 schema bytes with telemetry disabled; the profile also enables its new AST safe mode, which keeps ordinary `bpy` scene/render/save/import-export work and rejects interpreter, process, network, and persistence escape paths before code reaches Blender.
- RTK 0.47.0 is checksum-verified and remeasured. Its narrow standalone status and human-facing pytest/cargo/go routing remains default. Broad upstream routing still rewrites mutating Git, lossy diffs, broken compound find, search/read/curl/gh, and stays disabled. The published `--stat` benchmark is finally anchored to v8.6.5 instead of moving with HEAD.
- `TOOLS/audit_catalog_versions.py` derives registries from the install records already used as truth and checks npm, PyPI, GitHub, and Impeccable's secondary skill release. It is intentionally manual: upstream publishing timing must not randomly make an otherwise reproducible build red.

Windows MCP remains installed and off by default. Provider profiles still pay schema cost only when the project or user explicitly activates the capability.
