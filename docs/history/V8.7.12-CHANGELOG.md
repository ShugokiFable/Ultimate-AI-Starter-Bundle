# v8.7.12 -- local-only Hermes health probe

Hermes 0.21's `--version` command now checks upstream Git. That made the bundle's otherwise local installed-state doctor wait minutes on network state while validating a provider executable.

The doctor now uses Hermes' local argparse help path and retains `--version` for providers whose version command is local. A release contract binds the exception to the shared provider-probe loop so a future refactor cannot silently restore the fetch.

- 167 canonical skills across five provider trees.
- No MCP registrations or schema budgets changed.
- Windows MCP remains installed and off by default.
