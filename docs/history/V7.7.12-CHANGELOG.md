# v7.7.12 — Claude Desktop app MCP support

Add-Reasoning-MCPs.ps1 wrote only `~/.claude.json` (the Claude Code CLI
surface). The Claude Desktop app - normal or Microsoft Store installs - reads
its own `claude_desktop_config.json` and showed zero MCP servers even on fully
wired machines. The script now detects the desktop app's config (both install
types) and merges the same entries there, reusing the existing backup-and-merge
writer. `~/.claude.json` behaviour is unchanged.
