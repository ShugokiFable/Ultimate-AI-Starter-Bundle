# Ultimate AI Starter Bundle v7.8.0

## Reliability and one-shot success

- Added 57 concise, generic reliability/cognition skills covering CI convergence, one-shot completion, fresh-install proof, artifacts, recovery, state resumption, capability checks, reasoning economy, assumption audits, sibling regression sweeps, config preservation, path portability, version synchronization, side-effect safety, real-boundary testing, source authority, requirements traceability, evidence calibration, research freshness, edge cases, reproducible builds, rollback, security/trust boundaries, secret hygiene, performance evidence, automation, API compatibility, data integrity, concurrency, and observability.
- Reduced oversized always-loaded skill descriptions while preserving on-demand reference bodies.
- Fresh Windows installs can bootstrap missing Claude, Codex, Grok, Kimi, and Hermes CLIs using the vendors' official Windows installers, then verify each executable. Authentication remains an external account boundary and is reported explicitly rather than fabricated.
- Runtime bootstrap now fails on winget errors and installs/verifies the .NET 8 SDK required by the default Spooky component.
- Completeness-gate child-process provider lists are normalized. Codex uses skill/native-plugin enforcement instead of forcing a hook trust prompt; Hermes accepts only installer-owned hooks for the verification process.
- Bundles Skyrim Forge 5.2.0, installs it side-by-side, wires selected providers, and requires its legacy 7.8.x compatibility contract.
- Hermes fresh-install defaults are tuned for DeepSeek V4 Flash 0731 and long coding runs: maximum main-model reasoning (`max`); explicit tool-use/execution/completion/parallelization/verification guards; a 120k absolute compression cap with lean recovery-aware tails, 20 protected messages and at least 3 real user turns; 32k-token minimum proactive-prune reclaim; micro-compaction and time-only idle compaction disabled; fail-closed summary handling; one outer auxiliary retry; deliberate MCP reloads to preserve warm tool/prompt prefixes; and reasoning disabled on the mechanical compression auxiliary call. Automatic post-turn review forks and periodic skill-creation nudges are disabled because the bundle already ships a curated 143-skill library. Anthropic-compatible prompt caching uses the 1h tier; OpenRouter response caching/sticky routing remain enabled independently. The goal is fewer cache-invalidating rewrites, fewer redundant background calls, and fewer expensive repair loops.
- Added a final installed-state doctor before the success banner and deterministic ZIP builder that excludes developer state, CRC-tests, extracts under spaces/Unicode, and emits SHA-256 hashes.
