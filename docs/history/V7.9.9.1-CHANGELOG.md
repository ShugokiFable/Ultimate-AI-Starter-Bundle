# v7.9.9.1 — The always-on three

**2026-08-22.** Based on v7.9.9.

The release where the capability-profile policy stopped being documentation
and became the machine state. Every provider surface on the maintainer's
machine — Hermes, Claude Code, Claude Desktop, Codex, Grok — was flipped to
run exactly three always-on MCP servers (`context7`, `github`, `headroom`),
with everything else registered-but-disabled and enabled per task through the
`capability-profiles` skill (`Set-McpProfile.ps1`). Kimi is retired on the
machine; its tree still ships for everyone else.

---

## Why the policy moved from skill to default

v7.9.5–v7.9.8 built capability profiles and left application optional. Left
optional, nothing applied them: ~188–250 tool schemas (~90 tokens each)
stayed resident every turn across five surfaces while at most three servers
had work to do. The measured waste was the argument; the flip was overdue.

## What changed

- **Canonical skill**: `capability-profiles` now declares "the always-on
  three"; all five provider-tree copies byte-identical to canonical.
- **Surfaces**: Hermes entries flipped via `config set`; Claude Code global
  scope stripped to core with removed definitions preserved in
  `~/.claude/mcp-catalog.json`; Claude Desktop mirrored with its own catalog
  sibling; Codex non-core blocks commented out (`# off-v7.9.9.1:` markers,
  definitions intact); Grok explicit `enabled = false` everywhere non-core.
  Every edited file carries a `.bak-preprofile-*` backup.
- **SaintsRowForge** joins RobloxForge as registered-dormant (Hermes entry,
  `enabled: false`) rather than unregistered — zero token cost either way,
  but now discoverable and one flip from live.
- **MANIFEST.json regenerated** for all touched files; offline manifest,
  catalog and validation versions restated so the version gates hold.

## What did not change

No new skills (146 canonical across 5 trees). No server removed anywhere —
every disabled definition survives verbatim in place or in a catalog file.
Sequential-thinking stays demoted per v7.9.7 measurement. Firecrawl stays
keyless-unregistered per v7.9.9 measurement (2 of 25 tools usable without a
key duplicates native extraction).
