# Ultimate AI Starter Bundle — v6.5.0

Date: 2026-08-15
Base: v6.0.0

v6.5 targets one failure that no amount of instruction text has fixed: an agent
is **literal**. Told "push the fix", it pushes the fix — bumps the version,
commits, cuts a release, and never touches the README or the changelog, because
nobody asked it to. It is fast, it is efficient, and the result is wrong in a way
it cannot see.

Every provider's prompt already says "be thorough". So v6.5 stops asking.

---

## 1. The completeness gate (the actual deliverable)

`TOOLS/hooks/completeness_gate.py`, installed by
`TOOLS/Install-Completeness-Gate.ps1` into **Grok, Claude, Codex, Kimi and
Hermes** — all five read the same Claude-compatible hook shape.

| Hook | What it does |
|---|---|
| `PreToolUse` | Refuses `git push`, `gh release create`, `npm publish`, `twine upload`, `cargo publish` while the release is inconsistent. |
| `Stop` | Refuses to end the turn for the same reason, so the agent fixes it itself instead of handing you a half-release. |

It reports the specific inconsistency, not a nag:

- `CHANGELOG.md has no entry for 1.1.0 (declared in VERSION.txt).`
- `README.md still says 1.0.0 while VERSION.txt says 1.1.0.`
- `uncommitted source changes are not in this release: app.py, util.py`

**Design constraints, in priority order:**

1. **Precision over recall.** A gate that cries wolf gets turned off, and then it
   protects nothing. It engages *only* when the current commit changed a version
   declaration — the moment a release is actually happening — and is silent
   otherwise. Ordinary work never sees it.
2. **Cheap.** No network, no model call, no repo walk. A few file reads and one
   `git show --stat`. Zero tokens when clean; one short paragraph when it fires.
3. **Fails open.** Any error, any unknown payload, any non-repo: exit 0, say
   nothing. A broken gate must never be able to block work.

It also respects `stopHookActive`, so it states its case once and never loops,
and ignores the session-end `Stop` fire that has no turn left to continue.

`--selftest` proves all of it: catches the bump-without-docs case, stays silent
on a consistent release, on ordinary commits, and outside a repository. The
installer runs the self-test and **refuses to wire the hook if it fails**.

## 2. AIO-INSTRUCTION rewritten

The operating contract is now aimed at literalism and costs *less* than before:
**614 tokens, down from 640** — it is prepended to every request, so every line
had to earn its place.

The lead rule is "finish the job, not the sentence", stated concretely: bump a
version and the changelog and README are part of that bump; *"they didn't ask me
to update the README" is the mistake, not the defence.* It keeps the anti-yes-man
and never-invent rules, adds an explicit evidence order (runtime output beats a
linter beats docs beats recall), and requires the agent to report what it did
*not* do.

The routine confidence-score footer is gone. It fired on every answer including
one-liners, cost tokens each time, and said little; a confidence figure is now
reserved for answers that are genuinely uncertain or high-stakes.

## 3. BOOTSTRAP.txt

One block to paste into a fresh session of any agentic AI. It fetches the bundle,
runs the installer, installs the gate, verifies, and reports in under ten lines
what you still have to do by hand. No manual command entry.

## 4. Installer

`INSTALL-V6-AIO.ps1` now installs the gate as part of a normal run. The
interpreter is resolved by *running* candidates rather than trusting `PATH`, and
the Windows Store `WindowsApps` alias is deprioritised because it can be a stub
that opens a shop page instead of executing.

## Known limitations, stated plainly

- The gate catches **structural** incompleteness — version, changelog, README,
  uncommitted source. It cannot tell whether the changelog entry is *accurate*.
- Its trigger is a version-declaring file it recognises. A project that stores
  its version somewhere unusual gets silence, not a false alarm; that is the
  intended trade.
- Hooks load at app start, so every provider needs a full restart.
- The `Stop` gate is capped at 8 continuations per turn by the host, then the
  turn ends regardless. It cannot trap an agent in a loop.
