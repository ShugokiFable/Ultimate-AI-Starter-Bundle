# Limitations

Forge cannot honestly replace final in-game inspection of navmeshes, landscapes, worldspace placement, lighting, FaceGen appearance under the full visual stack, animation quality, dialogue timing, native-hook coexistence, save migration, balance, or crashes.

Creation Kit and Wrye Bash automation requires a compatible worker or a carefully calibrated UI job. LOOT analysis requires a compatible worker. The bundled Windows native helper is cross-compiled here and is executed by Windows CI and by the local installer.
