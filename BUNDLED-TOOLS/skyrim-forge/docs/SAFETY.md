# Safety

Forge uses workspace confinement, no-shell subprocesses, executable hashes, strict JSON, typed operations, explicit approvals, transaction folders, output hashing, audit receipts, overwrite refusal, and independent validation stages.

Do not point the workspace at Skyrim `Data`, Vortex staging, MO2 mods, Overwrite, profiles, or saves. External process execution and UI Automation are disabled by default.
