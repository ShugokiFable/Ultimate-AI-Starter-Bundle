# Workspace ownership

- Product: Skyrim Forge
- Authoritative repository: `https://github.com/ShugokiFable/SkyrimForge`
- Branch: `main`
- Parent: tag `v5.1.5`, commit `1e9f645`
- Active version: `5.2.0`
- Previous installed release: `Skyrim-Forge-5.1.5`

The Git repository owns the project. Keep that clone **beside** the versioned
install under the Skyrim tools folder (`<Skyrim Tools>\SkyrimForge` source,
`<Skyrim Tools>\Skyrim-Forge-5.2.0` live). Versioned folders are outputs, not
sources. Do not clone into Documents and do not treat
`Documents\Skyrim Forge` as an install — that was only the old default
workspace name.

Skyrim `Data`, mod-manager staging, profiles, saves, and reference vaults
remain read-only.
