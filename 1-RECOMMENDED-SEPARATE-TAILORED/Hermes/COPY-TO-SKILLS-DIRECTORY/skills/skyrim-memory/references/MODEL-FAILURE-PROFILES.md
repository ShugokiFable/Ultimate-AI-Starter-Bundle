# Provider execution profiles

These are routing controls, not rankings.

## Claude Code

Keep instructions concise, load only necessary skills, re-resolve the active
workspace, and compile exact review-driven changes.

## Codex

Inventory actual inputs, use one implementation owner for coupled artifacts,
compile the exact target, and synchronize isolated work back to the authoritative version.

## Grok Build

Plan before broad edits, reproduce the symptom, generate bulk output
deterministically, and validate binary/plugin work deeply.

## Kimi Code

Resolve `KIMI_CODE_HOME`, pass explicit context to isolated agents, use one
writer for coupled work, and verify the exact build and package.

## Hermes Agent

Resolve the active profile, keep project rules in workspace `AGENTS.md`, preserve
`SOUL.md` and native memory, and use the selected backend model under the same
validation gates.
