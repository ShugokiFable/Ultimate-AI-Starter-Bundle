# Kerbal Space Program 1

This skill targets KSP 1 unless the project explicitly proves another supported
toolchain. Pin the KSP and Unity versions, target framework, assembly references,
KSP API, dependency versions, and GameData root.

Validate Addon startup, PartModules, ConfigNodes, persistence, scenes, assets,
ModuleManager patches when used, save compatibility, and package layout.
