# Stellaris

Special systems include ethics, civics, authorities, origins, traits, species,
ships, components, technologies, traditions, ascension perks, anomalies,
archaeology, situations, first contact, events, deposits, districts, buildings,
jobs, scripted triggers/effects/modifiers, on_actions, and UI.

Use unique namespaces and object IDs. Avoid overwriting whole vanilla files when
an additive definition works. Test AI weights, scopes, event chains, localisation,
and existing saves.

Primary source:

- https://stellaris.paradoxwikis.com/Modding

Load `paradox-clausewitz-jomini-modding` first.
