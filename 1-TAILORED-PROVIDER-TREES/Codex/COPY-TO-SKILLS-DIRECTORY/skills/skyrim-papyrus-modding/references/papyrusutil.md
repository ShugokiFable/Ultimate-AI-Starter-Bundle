# PapyrusUtil selection reference

Use the exact installed PapyrusUtil source declarations. PapyrusUtil commonly provides `JsonUtil`, `StorageUtil`, `ActorUtil`, `ObjectUtil`, and related utilities.

Prefer it for straightforward JSON-backed configuration, key/value persistence, form lists/maps supported by the installed API, and interoperability with existing PapyrusUtil-based mods.

Verify function names and signatures from installed `.psc` files. Do not ship dependency `.pex` stubs used only for compilation.
