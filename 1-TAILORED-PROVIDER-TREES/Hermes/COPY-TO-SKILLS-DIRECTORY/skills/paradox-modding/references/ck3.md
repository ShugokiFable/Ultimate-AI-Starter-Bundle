# Crusader Kings III

Special systems include characters, dynasties, landed titles, cultures,
religions/faiths, traits, lifestyles, interactions, events, decisions,
activities, schemes, governments, contracts, struggles, history, scripted GUIs,
and portrait assets.

Validate scopes, saved scopes, triggers/effects, history dates, title hierarchy,
localisation, and save compatibility.
