# Noita

Noita combines Lua with entity-component XML/data. Validate mod directory,
init hooks, entity/component schemas, file-appending order, materials, spells,
translations, save/run behavior, and compatibility with other append-based mods.

Primary sources:

- https://noita.wiki.gg/wiki/Modding
- https://noita.wiki.gg/wiki/Modding:_Lua_API
