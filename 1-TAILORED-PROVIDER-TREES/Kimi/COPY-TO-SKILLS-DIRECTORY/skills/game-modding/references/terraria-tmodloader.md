# Terraria

Pin the tModLoader branch and Terraria version. A new Terraria release may not
yet be supported by stable tModLoader.

Validate content registration, hooks, ModSystem lifecycle, player/world save
data, packets, dedicated server, world generation, localization, assets,
build.txt metadata, dependencies, and Workshop packaging.

Primary sources:

- https://docs.tmodloader.net/
- https://github.com/tModLoader/tModLoader
- https://terraria.wiki.gg/wiki/TModLoader
