# Framework guide 2026

This is conceptual guidance. Executable syntax lives only in the dedicated skills.

| Framework | Use for | Do not assume |
|---|---|---|
| KID | Runtime keywords on supported records | That plugin signatures replace current type labels |
| SPID | Runtime distribution to NPCs | That distribution performs arbitrary removal |
| SkyPatcher | Supported runtime record mutations | That a key from another category/version exists |
| BOS | Base/reference swaps | That two historical dialects are interchangeable |
| MCM Helper | New JSON-backed configuration menus | That a legacy SKI menu should be migrated automatically |
| PapyrusUtil | Straightforward persistent values and JSON | That it replaces complex nested data modeling |
| JContainers | Nested/dynamic data structures | That handle lifetime and serialization are automatic |

Always route through `skyrim-frameworks-index`, then load the dedicated syntax owner.
