
# V4.2 runtime-log regression audit

This audit turns the supplied report into source-locked regression tests. It does
not treat every diagnosis in the report as correct.

## Verdict table

| Case | Log evidence | Corrected verdict | Skill control |
|---|---|---|---|
| Staves `Weapon =` | 2,616 unsupported-form-type failures | Broken. Current SPID has no `Weapon` key. Inventory weapons/staves use `Item` or intentional generic `Form`. Validate rows before mass replacement. | SPID key whitelist and fixture |

## Boundary

The skills can prevent known grammar, packaging, dependency-classification, and
over-attribution errors. They cannot statically guarantee that every external
mod, animation archive, native hook, visual preset, or runtime condition is
correct. Runtime logs and targeted in-game tests remain mandatory.
