Ultimate AI Starter Bundle V5.2.3 - ALL-IN-ONE STARTER
========================================

Not just Skyrim. This is a full multi-provider AI starter bundle:
skills, MCP tools, plugins, and offline installers - with a deep
optional Skyrim SE/AE modding stack built in.

NEW USERS - ONE COMMAND
-----------------------
Double-click:

    INSTALL-V5-AIO.bat

Or PowerShell from this folder:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\INSTALL-V5-AIO.ps1

That installs:
  - Provider skills (Claude, Codex, Grok, Kimi, Hermes)
  - houseCARL MCP (+ MO2 or Vortex shim setup) for Skyrim data-layer work
  - Spooky's AutoMod Toolkit
  - codebase-memory-mcp (code structure graph)
  - Headroom (context compression MCP - not Grok inference wrap)
  - Superpowers + Ponytail (skills/plugins)
  - CodeBurn (npm/npx, optional)
  - Optional extras: -WithExtras (code-review, obsidian, firecrawl, playwright, ...)
  - MCP wiring for the providers you select

Then FULLY restart your AI app(s).

OPTIONS
-------
  .\INSTALL-V5-AIO.ps1 -Providers Grok,Claude
  .\INSTALL-V5-AIO.ps1 -Mode OnlineLatest
  .\INSTALL-V5-AIO.ps1 -WithExtras
  .\INSTALL-V5-AIO.ps1 -WorkspaceRoot "D:\My\AI-Workspace"

CODEBASE-MEMORY (important)
---------------------------
Keep indexing manual:
  codebase-memory-mcp config set auto_index false
  codebase-memory-mcp config set auto_watch false
Index on demand with the index_repository tool.

The HTTP dashboard is optional and GLOBAL. --ui and --port persist in the
tool's own config and are shared by every AI app you have wired, so never put
them in MCP args - keep args = [] everywhere. A --ui=false sent from one
provider disables the dashboard for ALL of them on the next restart. Toggle it
once, out of band:
  codebase-memory-mcp --ui=true      (dashboard on, persisted globally)
  codebase-memory-mcp --ui=false     (dashboard off, persisted globally)
View at http://127.0.0.1:9749/ - graph, stats, ADRs; loopback only.
Do NOT run install.ps1 --ui (that installer flag is what causes the Windows
"Select an app / Codebase Discovery" dialog, not the dashboard itself).

V5.2.3 CODEBASE-MEMORY DASHBOARD GUIDANCE FIX
------------------------------------
Earlier packs said to NEVER enable the codebase-memory HTTP UI and shipped
`--ui=false`. That contradicted the Grok config this same pack writes, and
because the flag is global it silently disabled the dashboard for every
other AI app. Corrected above: keep MCP args empty, toggle --ui out of band.

V5.2.2 WINDOWS TERMINAL-FLASH FIX
------------------------------------
Normal setup now removes or disables stale Headroom scheduled tasks whose
deployment script or manifest no longer exists.
