Ultimate AI Starter Bundle V5.2.0 - ALL-IN-ONE STARTER
========================================

Not just Skyrim. This is a full multi-provider AI starter bundle:
skills, MCP tools, plugins, and offline installers - with a deep
optional Skyrim SE/AE modding stack built in.

NEW USERS - ONE COMMAND
-----------------------
Double-click:

    INSTALL-V5-AIO.bat

Or PowerShell from this folder:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\INSTALL-V5-AIO.ps1

That installs:
  - Provider skills (Claude, Codex, Grok, Kimi, Hermes)
  - houseCARL MCP (+ MO2 or Vortex shim setup) for Skyrim data-layer work
  - Spooky's AutoMod Toolkit
  - codebase-memory-mcp (code structure graph)
  - Headroom (context compression MCP - not Grok inference wrap)
  - Superpowers + Ponytail (skills/plugins)
  - CodeBurn (npm/npx, optional)
  - Optional extras: -WithExtras (code-review, obsidian, firecrawl, playwright, ...)
  - MCP wiring for the providers you select

Then FULLY restart your AI app(s).

OPTIONS
-------
  .\INSTALL-V5-AIO.ps1 -Providers Grok,Claude
  .\INSTALL-V5-AIO.ps1 -Mode OnlineLatest
  .\INSTALL-V5-AIO.ps1 -WithExtras
  .\INSTALL-V5-AIO.ps1 -WorkspaceRoot "D:\My\AI-Workspace"

HEADROOM + GROK (MCP only - do NOT wrap Grok inference)
-------------------------------------------------------
Headroom MCP tools are fine. Do NOT route subscription Grok through
headroom wrap / GROK_MODELS_BASE_URL (model shows as "unknown", 401s).

  .\TOOLS\Ensure-Headroom-Grok.ps1
  .\TOOLS\Ensure-Headroom-Grok.ps1 -Repair
  .\TOOLS\Ensure-Headroom-Grok.ps1 -CheckOnly

claude-mem is Claude Code only (needs Bun). Not for Grok/Codex/Kimi/Hermes.
