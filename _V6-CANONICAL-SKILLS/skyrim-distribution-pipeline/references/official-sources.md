# Runtime framework source map

Always inspect the installed release and bundled examples first.

- SPID: https://github.com/powerof3/Spell-Perk-Item-Distributor
- KID: https://github.com/powerof3/Keyword-Item-Distributor
- SkyPatcher: https://github.com/Zzyxz/SkyPatcher
- FormList Manipulator: search the installed powerof3 release and its examples
- Base Object Swapper: search the installed powerof3 release and its examples
- Open Animation Replacer: inspect the installed OAR documentation and condition examples
- Container distribution and race registration frameworks: verify the exact project and version before using any token

Do not mix syntax copied from different releases. A config that parses on one version can silently no-op on another.
