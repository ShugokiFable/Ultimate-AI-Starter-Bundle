# JContainers selection reference

Use the exact installed JContainers declarations. JContainers provides container-oriented APIs such as arrays, maps, form maps, databases, and JSON/Lua-oriented structures.

Prefer it when the data is nested, dynamic, or difficult to represent as simple scalar settings. Define ownership, lifetime, release/cleanup, save behavior, and migration.

Verify every function from installed `.psc` files. Do not ship dependency `.pex` stubs used only for compilation.
