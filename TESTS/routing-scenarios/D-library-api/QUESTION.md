# D. What the installed version actually does

## Ask

"What flags does the installed MCP-capable CLI on this machine accept for
attaching an image to a prompt?"

## Why it is a trap

Recall is fluent and wrong across versions; a web search returns blog posts
about other versions. The binary is on the machine.

## Pass

- asked the installed tool (`--help`, `--version`, subcommand help)
- distinguished "the flag exists" from "the path was tested end to end"
- named which source settled it

## Fail

- answered from memory
- searched the web before asking the installed binary
- cited docs for a version other than the installed one
