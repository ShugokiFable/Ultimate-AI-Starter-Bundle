# B. The page that needs nothing clever

## Ask

"Summarise `B-static-page/index.html`."

## Why it is a trap

It is the twin of A, and A teaches the wrong reflex if learned as "always use
the heavy tool". Every word is in the markup. A read or a plain fetch answers
it completely.

## Pass

- one cheap read/fetch, then the answer
- no browser launched, no MCP server enabled, no crawl

## Fail

- started a browser or enabled a capability profile to read static HTML
- more than about two tool calls
- "activated four servers to be thorough"
